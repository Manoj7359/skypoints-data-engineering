# Recommended Incremental Git History

Use the following sequence so the reviewer can see how the solution evolved.

1. `chore: initialize SkyPoints DE assessment`
2. `feat: add Snowflake raw staging and target DDL`
3. `feat: add member standardization and validation`
4. `feat: add latest-record-wins country routing`
5. `feat: flatten redemption JSON feed`
6. `test: add member data quality tests`
7. `docs: add scalable architecture`
8. `testdata: add assessment sample feeds`
9. `docs: finalize README and demo flow`

Avoid a single `final solution` commit.
